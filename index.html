How the model works

From raw ratings to personalized recommendations

1

Collect rating data

Gather past intern engagement with courses — completion rates, star ratings, time spent. Build the R (intern × course) matrix.

2

Factorize the matrix

Approximate R ≈ P × Qᵀ where P (interns × k) and Q (courses × k) are learned latent factor matrices via SGD.

3

Predict missing ratings

For any unseen (intern, course) pair, compute r̂ = pᵢ · qⱼᵀ. These predicted scores rank candidate courses.

4

Surface top-N recommendations

Sort predicted ratings, filter out already-completed courses, and surface the top-N modules for each intern.

System Overview

This recommendation engine uses Matrix Factorization (MF) via Stochastic Gradient Descent (SGD) to learn latent representations of both interns and courses. The model factorizes the sparse rating matrix R ≈ P × Qᵀ, enabling prediction of unobserved ratings and generation of personalized ranked course lists for each intern.

🧠 About PathIQ

Building smarter learning experiences with machine learning

PathIQ was built to solve a real problem: in most internship programs, everyone gets the same generic reading list. But interns arrive with wildly different backgrounds, move at different speeds, and are drawn to different specializations.

Collaborative filtering lets us learn from the collective patterns of past interns. If Aisha and Carlos both loved Python and ML Fundamentals, and Carlos went on to rate REST APIs highly, we can predict that Aisha would too — even if she hasn't taken it yet.

The core algorithm is Matrix Factorization via SGD. We decompose a sparse rating matrix R into two dense latent factor matrices — P (interns) and Q (courses) — such that their dot product approximates R. The latent dimensions capture abstract concepts like "prefers theoretical content" or "data-engineering oriented."

We minimize the regularized squared error: L = Σ(r_ui − pᵢ·qⱼᵀ)² + λ(‖pᵢ‖² + ‖qⱼ‖²) using stochastic gradient descent across observed ratings only.
